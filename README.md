# bmstu-sob 1.1.0

Строгий LaTeX-комплект для отчётов и пояснительных записок МГТУ им. Н. Э. Баумана с опорой на ГОСТ 7.32-2017.

## Нормативная база

Основной университетский профиль в этой версии ориентирован на действующее Положение МГТУ им. Н. Э. Баумана о порядке подготовки и защиты ВКР, утверждённое приказом от 26.12.2024 № 02.01-02/811, а также на ГОСТ 7.32-2017.

Проверенные базовые параметры текущего профиля МГТУ:

- A4, односторонняя печать;
- Times New Roman, 14 pt;
- полуторный межстрочный интервал;
- поля: 30 / 15 / 20 / 20 мм (левое / правое / верхнее / нижнее);
- абзацный отступ 1,25 см;
- выравнивание по ширине;
- автоматические переносы;
- сквозная нумерация страниц арабскими цифрами внизу по центру.

ГОСТ 7.32-2017 в актуальной карточке Росстандарта отмечен как действующий.

## Почему сохранён вариант 30/10/20/20

В классе оставлен явный ключ `[legacy10]`. Он **не является текущим профилем МГТУ по умолчанию**. Он предназначен для кафедральных/старых методических указаний, где отдельно прямо установлено правое поле 10 мм.

Таким образом:

```text
bmstu-sob                 30/15/20/20  <- текущий основной профиль
bmstu-sob[gost]           30/15/20/20  <- геометрически тот же профиль
bmstu-sob[legacy10]       30/10/20/20  <- только при явном локальном требовании
```

Это сделано намеренно: когда университетское требование и ГОСТ дают один и тот же параметр, класс не создаёт искусственный второй вариант.

## Компиляция

Класс требует XeLaTeX или LuaLaTeX, потому что базовый профиль требует реальный системный Times New Roman и Courier New.

Пример:

```latex
\documentclass{bmstu-sob}

\begin{document}

\section{Введение}

Текст документа.

\subsection{Постановка задачи}

Текст подраздела.

\bmstuConclusion

Текст заключения.

\end{document}
```

Для старой кафедральной схемы с правым полем 10 мм:

```latex
\documentclass[legacy10]{bmstu-sob}
```

Для лабораторных:

```latex
\documentclass{bmstu-sob-lab}
```

Лабораторный класс не навязывает 10 мм автоматически; локальное требование можно указать:

```latex
\documentclass[legacy10]{bmstu-sob-lab}
```

## Рисунки и таблицы

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=.7\textwidth]{figure.png}
  \caption{Пример рисунка}
  \label{fig:example}
\end{figure}
```

Подпись рисунка будет вида `Рисунок 1 – Пример рисунка`.

```latex
\begin{table}[htbp]
  \caption{Пример таблицы}
  \label{tab:example}
  \centering
  \begin{tabular}{ll}
    Параметр & Значение \\
    A & 10 \\
  \end{tabular}
\end{table}
```

Таблицы допускают меньший размер шрифта, поэтому содержимое стандартного `tabular` набирается 12 pt. Это не меняет основной шрифт документа.

## Формулы

```latex
\begin{equation}
  A = \frac{B}{C}
  \label{eq:test}
\end{equation}

\begin{bmstuwherelist}
  \bmstuwhereline{$B$ — числитель;}
  \bmstuwhereline{$C$ — знаменатель.}
\end{bmstuwherelist}
```

Формулы имеют сквозную нумерацию `(1), (2), ...`; в приложениях — `(А.1), (А.2), ...`.

## Приложения

Перед приложениями:

```latex
\appendix
\bmstuAppendix{Исходный код программы}
```

Затем при необходимости можно использовать разделы приложения обычным `\section`/`\subsection`.

Перед приложениями создаётся отдельная страница `ПРИЛОЖЕНИЯ`. Каждое приложение начинается с новой страницы и обозначается кириллическими буквами по ГОСТ: `А, Б, В, ...` с исключением `Ё, З, Й, О, Ч, Ъ, Ы, Ь`.

Графика, таблицы и формулы приложений получают нумерацию вида `А.1`.

## Библиография

Для полностью автоматизированной библиографии можно подключить `biblatex` + `biblatex-gost`:

```latex
\documentclass[biblatex]{bmstu-sob}
\addbibresource{references.bib}
...
\printbibliography[title={Список использованных источников}]
```

Вызов `\bmstucite{key}` является тонкой обёрткой над `\cite`.

Положение МГТУ требует библиографическое описание по ГОСТ Р 7.0.100-2018 и допускает порядок по алфавиту или порядок появления ссылок.

## Установка в TeX Live

В архиве есть:

Рекомендуемый путь установки определяется из `kpsewhich -var-value=TEXMFLOCAL`; скрипт помещает пакет в локальное дерево `tex/latex/bmstu-sob/` и запускает `mktexlsr`.

Ручная проверка после установки:

```text
kpsewhich bmstu-sob.cls
kpsewhich bmstu-sob-lab.cls
```

Команды должны вернуть путь к файлам в локальном дереве TeX Live.

## Ограничения

Класс обеспечивает воспроизводимую вёрстку, но не может автоматически проверить содержательную часть работы. В частности, автор должен сам обеспечить наличие ссылок на используемые рисунки/таблицы/приложения, корректность библиографических записей и соответствие текущим кафедральным формам титульного листа, задания и других бланков.
